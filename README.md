# Battery SOH Prediction using NASA Dataset | IITK SEE

Developed by Kanak Mishra @ IIT Kanpur - Sustainable Energy Engineering

## Project Overview
Predicted State of Health (SOH) of Lithium-ion battery using Voltage, Current, Temperature and Cycle Number.
- Dataset: NASA B0005 Type (1000 cycles)
- Model: RandomForestRegressor
- Accuracy: Train 97.08% | Test 80.27%
- Fixed Overfitting issue (34% -> 80%)

## What is SOH?
SOH = Battery ki Health. Nayi battery 2.0 Ah, purani 1.2 Ah

## Tech Stack
Python, Pandas, Scikit-Learn, Google Colab

## Results
Model successfully predicts Capacity (Ah) from sensor data.
